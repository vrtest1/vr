# OceanEngine

風で決まる波、空の反射、太陽の照り返し、白波、浅瀬と波打ち際までを描く海面です。

![波打ち際（high プリセット、地形 + 大気 + 海）](../../docs/images/ocean-shore.png)

- デモ: `examples/ocean/`（地形 + 大気 + 海）　最小サンプル: `examples/ocean/minimal.html`（海だけ）
- 依存: three.js（r170 で確認）、`src/core/`

## 仕組み

- **メッシュ** — カメラを中心にした極座標の格子 1 枚。リングの間隔を外側ほど等比で広げ、水平線まで届かせます。カメラが高く上がると格子全体が広がります。メッシュの作り直しはありません。
- **波** — Gerstner 波の重ね合わせ。風速から有義波高（0.21·U²/g）と卓越波長を決め、その海の状態に合う波の表を CPU で作ります。同じ表を、頂点の変位・ピクセル単位の法線・CPU の高さ問い合わせの 3 か所で使います。
- **ディテールの振り分け** — メッシュで表せる長い波だけを頂点で動かし、短い波は法線で表現します。画素より細かい波は法線から外し、その分だけ表面を「粗く」するので、遠くの照り返しが点滅せず帯状に広がります。
- **光** — シーンにある光源をそのまま使います（最初の DirectionalLight が太陽、最初の HemisphereLight が空）。影も受けます。反射する空の色は `WorldEnvironment` の `skyZenith / skyHorizon / skyHorizonSun` から取ります。AtmosphereEngine があればそれが正確な値を書き込み、なければ時刻と天候からの概算になります。
- **海底** — `seabed` に地面の高さを返す GLSL を渡すと水深が分かり、浅瀬の色、底が透ける透明度、岸で静まる波、波打ち際の泡が有効になります。

## API

```js
const ocean = new OceanEngine({
  environment,
  quality: 'high',
  params: { choppiness: 0.9 },
  seabed: terrain.getHeightShader({ functionName: 'pwoSeabedHeight', octaves: 8 }),  // 省略可
});
ocean.addTo(scene);
atmosphere.applyTo(ocean.material);   // 空気遠近を付ける場合
ocean.update(deltaTime, camera);      // 毎フレーム
```

`seabed` は `{ glsl, uniforms }` で、`glsl` が `float pwoSeabedHeight(vec2 xz)`（地面のワールド高さ、m）を定義していれば何でも構いません。TerrainEngine を使わない場合も、自前の高さ関数を渡せます。

### OceanEngine 固有

| メンバー | 意味 |
|---|---|
| `getHeightAt(x, z)` | その瞬間の水面の高さ（m）。浮かぶ物体用。波の水平方向の動きと岸での減衰は含まない近似 |
| `significantWaveHeight` | 現在の有義波高（m） |
| `material` / `mesh` | 水面のマテリアル / Mesh |

### パラメータ

| 名前 | 既定値 | 範囲 | 意味 |
|---|---|---|---|
| `waveHeight` | 1 | 0–4 | 風から決まる波高への倍率 |
| `choppiness` | 0.8 | 0–1.2 | 波頭の尖り具合 |
| `spread` | 0.55 | 0–1.5 | 波の向きのばらつき（rad 相当） |
| `ripples` | 1 | 0–3 | さざ波の強さ |
| `timeScale` | 1 | 0–4 | 波の時間の速さ |
| `seed` | 7 | 0–9999 | 波の並びの種 |
| `deepColor` | `#123f52` | 色 | 深い水の色 |
| `shallowColor` | `#5cc2b0` | 色 | 浅瀬の色（`seabed` 指定時） |
| `scatterColor` | `#35d6b4` | 色 | 逆光で波頭を透ける光の色 |
| `reflection` | 1 | 0–2 | 空の反射の強さ |
| `clarity` | 5 | 0.5–60 | 底が見えなくなる水深の目安（m） |
| `foam` | 1 | 0–3 | 白波の量 |
| `foamThreshold` | 0.42 | 0–1.5 | 白波が立ち始める波の急峻さ |
| `shoreFoam` | 1 | 0–3 | 波打ち際の泡の量 |
| `shoreDepth` | 5 | 0.5–40 | 岸に向かって波が静まり始める水深（m） |
| `viewDistance` | 40000 | 500–200000 | 格子が細かく刻まれる範囲（m）。その外側は水平線まで平らな面 |
| `receiveShadow` | true | — | 影を受ける |
| `wireframe` | false | — | ワイヤーフレーム |

### WorldEnvironment との対応

| 環境の値 | 効果 |
|---|---|
| `windSpeed` | 波高・波長・白波・照り返しの幅 |
| `windDirection` | 波の進む向き、さざ波と泡の流れ |
| `waterLevel` | 水面の高さ |
| `skyZenith / skyHorizon / skyHorizonSun` | 反射する空の色 |

風速と有義波高の目安: 4 m/s → 0.34 m、10 m/s → 2.1 m、15 m/s → 4.8 m（上限 14 m）。

## パフォーマンス実測

Apple M4 Max、Chrome（ヘッドレス、ANGLE Metal）、1280×720、地形 + 大気 + 海のデモの波打ち際（画面の半分ほどが海）。3 エンジンとも同じプリセットです。

| プリセット | FPS | GPU 時間（3 エンジン合計） | CPU 時間 |
|---|---|---|---|
| ultra | 60（上限） | 10.8 ms | 0.1 ms |
| high | 60（上限） | 7.9 ms | 0.7 ms |
| medium | 60（上限） | 3.8 ms | 0.6 ms |
| low | 60（上限） | 1.7 ms | 0.6 ms |

海を足したことによる増加は high で約 2–3 ms です。主な負荷は、海面の画素ごとに評価する波の法線と海底の高さ関数です。**iPhone と Quest 3 ではまだ計測していません。**

## 既知の制限

- **波は正弦波の重ね合わせ。** FFT による海洋スペクトルではないので、少ない波数（low / medium）では波の並びに規則性が見えることがあります。砕ける波（巻き波）は表現できません。
- **風が変わると波が瞬時に切り替わる。** 風速・風向を変えた瞬間に波の表を作り直すため、なめらかな移行はしません。
- **反射は空の色のグラデーションだけ。** 雲、地形、物体は水面に映りません（スクリーンスペース反射や平面反射は未実装）。
- **水中の屈折がない。** 浅瀬は「底が透ける」だけで、底の像は屈折で歪みません。水面を下から見たときは、真上に空が丸く見える「スネルの窓」と、その外側の全反射を描きます。水中の色や光芒は UnderwaterEngine の担当です。
- **波打ち際の泡は水深から作る模様。** 実際の波の遡上（濡れた砂が広がる動き）とは連動しません。
- **`getHeightAt` は近似。** 波の水平方向の動きを無視するので、`choppiness` が高いと波高の数割ずれることがあります。岸近くの波の減衰も CPU 側では考慮しません。
- **海底の指定は構築時のみ。** `seabed` を後から付け外しするにはエンジンを作り直します。
- **湖と海の区別がない。** 水位より低い場所はすべて同じ水面・同じ波になります（内陸の小さな池にも沖と同じ風の波が立ちます。ただし浅ければ静まります）。
- **格子の中心付近。** 真上から至近距離で見下ろすと、放射状の格子の中心が波の形に現れることがあります。
- **three のバージョン依存。** ライト・影・フォグのシェーダチャンクを使っています。r170 で確認。
