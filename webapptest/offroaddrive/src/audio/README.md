# AudioEngine

Web Audio API による環境音。音声ファイルは 1 つも読み込まず、すべてノイズと短い合成音から作ります。

依頼文の 7 モジュールには含まれていない、追加の 8 つ目のモジュールです（ユーザーの要望で追加）。

- デモ: `examples/underwater/`（映像つき）　最小サンプル: `examples/audio/minimal.html`（音だけ、波形表示つき）
- 依存: `src/core/`、three.js（リスナー位置の取得に Vector3 を使うだけ）

## 音の層

| 層 | 作り方 | 何に従うか |
|---|---|---|
| 風 | 低域寄りのノイズをバンドパス。強風では高域の「ヒュー」を足す | 風速（音量と音の高さ）、数秒ごとの突風のゆらぎ |
| 波 | ノイズをバンドパスし、波の周期で音量と音色を上下させる | 風速（荒さと周期）、水辺までの近さ |
| 雨 | 高域のノイズ | `precipitation`（気温が 0.5 ℃ 以下なら雪とみなして小さく） |
| 水中 | 低いごろごろ音 + 泡（上昇するサイン波の短い音） | カメラが水面下か、水深 |

水面下に入ると、水上の音（風・波・雨）はまとめてローパスフィルタで「こもった音」になり、潜った瞬間に泡がまとまって鳴ります。

## API

```js
const audio = new AudioEngine({
  environment,
  waterHeight: (x, z) => ocean.getHeightAt(x, z),       // 省略時は平らな水位
  groundHeight: (x, z) => terrain.getHeightAt(x, z),      // 省略可。渡すと波の音が場所で変わる（下記）
  waterProximity: (position) => 0..1,                     // 省略時は水面からの高さで減衰
});
button.onclick = () => audio.start();     // ブラウザの制約で、最初はユーザー操作から
audio.update(deltaTime, camera);          // 毎フレーム
```

| メンバー | 意味 |
|---|---|
| `await start()` | 音声グラフを作って再生開始。初回はクリック・キー・タッチのハンドラ内から呼ぶ |
| `await stop()` | 一時停止（`start()` で再開） |
| `running` | 再生中か |
| `submerged` | 直近の `update()` でリスナーが水面下だったか |
| `analyser` | 最終出力に付いた AnalyserNode（メーターやテスト用） |
| `context` | AudioContext（`start()` まで null。コンストラクタの `context` で既存のものを渡せる） |

### 波の音が聞こえる場所

`groundHeight` を渡すと、エンジンが聞き手の周りの地面を調べて波の音の大きさを決めます（0.3 秒ごと、25 点）。

| 場所 | 波の音 |
|---|---|
| 海の岸（近くに陸と水の両方があり、その先に開けた水面がある） | 大きい |
| 沖（周りがすべて水） | 岸の約 4 分の 1。静かなうねりの音 |
| 湖や入り江の岸（数百 m 先が陸） | ごく小さい |
| 湖の真ん中、内陸 | なし |

`waterProximity` を渡した場合はそちらが優先され、`groundHeight` は使われません。どちらも渡さなければ、水面からの高さだけで決まります。

### パラメータ

| 名前 | 既定値 | 範囲 | 意味 |
|---|---|---|---|
| `volume` | 0.7 | 0–1 | 全体の音量 |
| `wind` / `waves` / `rain` / `underwater` | 1 | 0–2 | 各層の音量 |
| `bubbles` | 1 | 0–3 | 泡の量と音量 |
| `waterReach` | 120 | 5–2000 | 海の音が聞こえる高さの目安（m）。`waterProximity` を渡した場合は使わない |

### 品質プリセット

| | ultra / high / medium | low |
|---|---|---|
| 泡の合成音 | あり | なし |
| 突風のゆらぎ | あり | なし |

音の処理はブラウザの音声スレッドで行われ、描画の負荷にはほぼ影響しません（常時鳴っているのはノイズ源 5 本とフィルタ 7 個）。

## 確認方法と結果

ヘッドレス Chrome で、出力の実効値（RMS）と 400 Hz 未満の成分の割合を AnalyserNode で測りました。

| 状況 | RMS | 400 Hz 未満の割合 |
|---|---|---|
| 岸辺、風速 3 m/s | 0.018 | 5 % |
| 岸辺、風速 20 m/s | 0.137 | 1 % |
| 岸辺、雨 | 0.105 | 0 % |
| 内陸の上空 1500 m、風速 6 m/s | 0.005 | 1 % |
| 水深 8 m | 0.064 | 99 % |
| `volume: 0` | 0 | — |

状況に応じて音量と音域が切り替わることは数値で確認し、波音と水中の音は実際に聞いて「それらしく聞こえる」ことを確認しています。強風・雨・泡の量など、細かい音色の調整はまだしていません。

## 既知の制限

- **波の音の場所の判定は粗い。** 30 m・90 m・400 m・1200 m の輪の上の点が水かどうかだけを見ています。細い水路や小さな島では実際と合わないことがあります。湖かどうかは水面の広さで見分けているので、とても大きな湖は海として扱われます。岸の向き（波が打ち寄せる側かどうか）は考えません。

- **音色の細かい調整はまだ。** 波音と水中の音は試聴済みですが、強風や雨の聞こえ方は詰めていません。
- **定位がない。** 音はモノラルの環境音で、波の方向や距離による左右の違いはありません（PannerNode は使っていません）。
- **個別の出来事の音はない。** 波が岸で砕ける瞬間、雷、鳥や虫、足音などはありません。波の音は映像の個々の波とは同期せず、風速から決まる周期で上下するだけです。
- **水面の出入りは瞬時に切り替わる。** 水しぶきの音はなく、泡がまとまって鳴るだけです。
- **ユーザー操作が必要。** ブラウザの自動再生制限のため、`start()` はクリックなどのハンドラから呼ぶ必要があります。iOS の消音スイッチが入っていると鳴りません。
- **XR では未確認。**
