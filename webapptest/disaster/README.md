# VOLT Disaster v3.6 — 300km LOD — 第一段階の実装

店舗検索なしの `VOLT_Final_Mobile.zip` をベースにした、手動取得型の災害情報3Dビューアです。
**本版は公式発表の履歴を表示する初期実装です。全国の現在有効な警報を完全に復元する運用版ではありません。**

## 起動

GitHub Pagesの新しいフォルダー（例：`disaster/`）へ、このフォルダーの内容をまとめて配置してください。
`index.html`、JS/CSS、`vendor/` の相対配置を維持します。npmビルド、APIキー、中継サーバーは不要です。
既存の `/volt/` を上書きする必要はありません。今回、既存の公開サイトは変更していません。

ローカルでは、このフォルダーで `python -m http.server 8000` を実行し `http://localhost:8000` を開きます。
HTMLファイルのダブルクリック（file://）は対象外です。現在位置にはHTTPSまたはlocalhostとブラウザの許可が必要です。

1. 起動時は火山だけを一度取得します。ほかの種類はチェック時に追加取得。「災害情報を更新」は選択中の種類を更新します。常時ポーリングはありません。
2. 発表一覧で情報を選択します。「この地点へ移動」で震源・火山へ移動できます。
3. 地図上のマーカー・ラベル・予報輪郭線からも詳細を開けます。
4. フィルターで種別・信頼性を切り替えられます。JSON保存は取得した共通イベントデータを保存します。

## 実データと未実装の区別

|情報|今回の実装|制約|
|---|---|---|
|地形・航空写真・地図|既存の国土地理院タイル表示|カメラ周辺300km四方を覆う自動LOD。タイル境界に合わせるため外周は300kmより少し広くなります|
|地震|気象庁XMLの震源、最大震度、各市町村の震度、発生時刻・規模を解析|3D表示は震源の地表投影。震度分布の面・観測点位置は未実装|
|火山|公式位置と本文、公式降灰予報ポリゴン|予報は観測事実ではありません。輪郭線は対象時間内のみ表示。危険半径・煙は生成しません|
|津波|対象となる公式XMLがフィードにある場合、発表履歴・本文・対象地域を表示|沿岸形状・到達時刻の構造化表示は未実装。v3.4では地名検索で一意に対応する場合のみ地域代表点を表示|
|気象警報・土砂災害|高頻度フィード内の該当XMLの履歴・本文・地域名|有効警報の全件スナップショットではありません。区域ポリゴンは未実装|
|道路規制・鉄道|未接続と表示、チェック無効|0件取得済み・規制なしとは表示しません|
|SNS・ニュース・AI|未実装|信頼性区分と共通イベントへの接続点のみ用意|
|デモ情報|アプリには一切なし|tests/fixturesは解析テスト専用の過去の実XML。アプリは読み込みません|

## 重要な読み方

- 「公式確認」は発表機関の区分です。公式の予報が的中することや、現地の安全を保証する区分ではありません。
- 公式降灰予報には「噴火が発生した場合」の条件があります。噴火発生・降灰観測と同一視しません。
- 取得時刻、情報更新時刻、発表時刻、有効期限を分離しています。時刻はJSTで表示します。
- 「情報なし」は安全を意味しません。避難ルート推奨や安全判定は行いません。
- このアプリは全後続電文を復元しません。取消は解析した電文について非表示にしますが、全国の解除・訂正を網羅できたとは扱いません。
- 手動取得をしても、公式配信自体の遅延・停止は解消されません。現在の有効警報は気象庁等の元情報で確認してください。

## 取得負荷

高頻度の地震火山、長期の地震火山、高頻度の随時情報の3フィードを読みます。
選択した種類の対応XMLを公開フィードから新しい順に全件取得します。50件上限と降灰予報の見出しによる事前間引きは撤廃。URL重複を除き、解析後の同一事象の続報・訂正は最新に統合します。
個別XMLはセッション内で最大180件キャッシュ。同時リクエストは3、タイムアウト18秒、フィード一覧は1分間再利用します（種類追加を妨げません）。
長期フィードの全国全電文を解析する設計ではありません。キャッシュは再読み込みで破棄されます。

## ファイルと構造

- `terrain.js`：元VOLTの地形処理を継承。v3ではlod-terrain.jsがズーム9〜13の地形処理を管理します。
- `app.js`：元VOLTのWebGPU/WebGL2初期化、カメラ、キーボード・タッチ操作、地名検索、地図切替を継承。現在位置ボタンを追加。
- `events.js`：共通イベント、座標、信頼性、訂正の統合、有効期限。
- `jma-source.js`：公式フィード・XML取得、名前空間対応の解析、共通イベント変換。Three.js非依存。
- `visualization.js`：共通Visualization SchemaからThree.jsのマーカー・線を生成。API非依存。
- `disaster-ui.js`：手動取得、一覧、詳細、フィルター、出典、JSON出力。
- `DATA_SOURCES.md`：利用条件・CORS・GitHub Pagesの制約と調査結果。
- `ARCHITECTURE.md`：8項目の構造整理、拡張契約と未実装項目。
- `tests/`：実XML解析テスト。通常起動に不要。

雨粒、雨雲、稲妻、雷鳴、タップ落雷、時間帯・風速等の雷雨設定と専用モジュールは除去しました。
雷の発光用ポスト処理も除去し、Three.jsで直接描画します。地形メッシュ生成・DEM処理は継承しています。v3ではタイル選択を自動LODへ変更しました。

## v3：300km LODとDEM欠損対策

### 操作

画面下部の「広域300km」を押すと広域俯瞰へ移動します。「上空」「地上付近」で近景に戻れます。
高空では移動・ホイール・ピンチの速度が高度に応じて上がります。フォグOFF、明るさスライダーは維持しています。

### LODと軽量化

- カメラ周辺の300km四方を覆うタイルを選択（タイル境界まで外周が広がります）。平面メルカトル座標上の概算で、地球曲率は未対応です。
- ズーム9〜13の5段階。距離と高度で詳細度を調整。近景z13は元VOLTと同じ48分割。中景32、遠景16分割。
- 選択タイルは親フォールバック込み最大240、各レベル64まで。GPUスロットは必要時のみ生成し再利用、全レベル合計上限320。
- 親を残し、子4領域の準備が整ってから切り替えます。親子の面を同時に重ねない方式です。
- 小移動で計画を繰り返さない1km単位の更新と、切替閾値の余裕によりLODの往復を抑えます。
- 地形ロードは最大4タスク、地理院タイルのHTTP取得は最大6並列。
- 圧縮画像のメモリキャッシュ16MiB、共有DEMキャッシュ96件、404記録512件・5分。永続的な巨大データ保存はしません。
- 遠景では粗い全球DEMを使用し、詳細DEMの不要な取得を減らします。
- 省電力時は遠方の細分化を抑え、描画を約30fpsに制限。非表示タブでは描画を止めます。
- 高空での奥行き精度を改善するため、カメラのnearを高度に応じて調整。farは650km。

### DEM 404について

ご提示の `/dem_png/13/7071/3337.png` は実際に404、親の `/dem_png/12/3535/1668.png` と `/demgm_png/8/220/104.png` は200を確認しました。
存在しないタイルへの最初のリクエストはブラウザのコンソールに404が残り得ます。エラー表示を隠す方式ではありません。
詳細DEMが欠ける場合は親DEM・全球DEMへフォールバックします。それも取得できない場合は地図画像を暫定平面に描き、「標高・画像が不足（代替表示）」と件数表示します。この平面は実標高ではありません。
移動前の応答が移動後の地形へ混ざらない世代・スロット検証も維持しています。

### 検証と残る制約

- 日本周辺の緯度・経度と複数高度で、300km範囲の包含・親子非重複・タイル数制限を自動テスト（最大238選択）。
- Three.jsの実ジオメトリを使い、標高全欠損時の平面表示、親DEM代替、地点切替中の遅延応答排除、LOD読込完了、標高参照をテスト。Canvas描画と通信はテスト用代替です。
- 全JS構文・UI参照を確認。
- 実ブラウザでのGPU描画・見た目・FPSは未検証です。実際の軽量化率を測定したものではありません。
- 異なるLOD間は境界スカートで隙間を隠します。地形の連続的な変形は未実装で、解像度切替時の見た目の変化はあり得ます。
- 地図表示とは別に、災害データは第一段階の対応範囲のままです。

テスト：`node tests/lod.test.mjs`、`node --experimental-loader ./tests/three-loader.mjs tests/terrain.test.mjs`。

## v3.3 — 指定避難場所・避難所

操作パネルの「周辺の避難場所・避難所を取得」でカメラ直下の位置を中心に半径5kmを手動取得します。通常の災害更新とは独立したボタンです。移動後は再取得してください。取得中心と取得時刻を表示し、近い200件まで描画・一覧化します。取得失敗タイルと404のデータ未提供タイルは別に表示します。全国300km分の施設を一括取得しません。

国土地理院の公式GeoJSONタイル（z10、skhb01〜08、sih、sfh）をキーなしで利用。同じ緊急避難場所の災害別重複を統合します。一般・福祉避難所と緊急避難場所の区分は保持します。対応災害、住所、受入対象者、備考、出典と取得時刻を表示。施設ごとの公表・更新日時はデータにないため不明とし、取得日時で代用しません。公式確認は施設の指定情報の出典を示すだけで、開設・受入可否は未確認です。

指定緊急避難場所は災害別の退避先、指定避難所は一時的な避難生活の施設です。データは随時更新され、古い情報や未掲載があります。最新状況と開設・受入条件は市町村に確認してください。経路の安全性は判断しません。

実データ：国土地理院の指定施設情報。デモ表示なし。道路・鉄道は引き続き未接続。実GeoJSONで解析を確認し、Origin付きskhb04リクエストのCORS許可(*)を確認。自動テストで重複排除、取得範囲・件数・同時通信数、欠測・失敗、連続地点移動を確認。実ブラウザのGPU画面確認は未実施。

## v3.4 — 地名から発表対象地域の代表点を表示

「災害情報を更新」で公式座標のない発表について地名検索を実施します。1更新あたり最大30地域を順次取得（1件最大8秒）、結果を15分・最大256件キャッシュします。公式XMLの地域名とコードを保持し、都道府県コードを利用できる場合は県名で絞り込みます。地名が一致し一意に決まる結果だけを採用し、施設名など部分一致や同名地域の曖昧な候補は採用しません。「○○県北部」など対応する検索結果がなければ未配置のままです。

紫の「地」は発表対象地域の位置の目安であり、災害発生地点・震源・影響範囲・厳密な地理的中心ではありません。解除などを含む発表履歴の対象地域であって、現時点の警報発令地域を復元したものでもありません。詳細の地域別ボタンから移動し、検索元を開けます。

公式発表のstatus=CONFIRMEDは保持し、位置に別途locationStatus=ESTIMATEDを付与。元のlatitude/longitudeがない場合はnullのまま、areaLocationsとVisualizationに検索結果・根拠・検索URL・時刻を記録します。「推定」をOFFにすると代表点の描画を隠します。公式震源座標がある地震は代表点検索を行いません。震度速報・震源に関する情報もフィード選択対象に追加しました。

実地名検索の取得とCORS、同名・部分一致除外、公式位置保護、取消除外、検索上限・キャッシュ、XML解析と連続移動テストを確認。ブラウザの実GPU表示は未確認。デモマーカーはありません。

- ピンチやドラッグ後の誤マーカー選択を抑制し、単純なタップのみ選択扱いにします。
- スマホの入力欄・選択欄を16px以上にして入力フォーカス時の自動拡大を抑制。検索実行時にキーボードを閉じます。
- touch-action: manipulationで操作部のダブルタップズームを抑制。地図キャンバスはブラウザのズームではなく地図専用ジェスチャーとして処理。user-scalable=noやmaximum-scaleは設定せず、パネル上でのアクセシビリティ用ページ拡大とスクロールは残します。既に手動で拡大したページを強制的に縮小する処理はありません。
- 自動テスト：1本指移動、ピンチ・回転・傾き、2本→1本の切替、誤タップ抑制、キャンセル・blur、PC操作、座標計算、地図の連続移動と破線描画資源。実機iPhone/Safariのジェスチャー・キーボード挙動は未検証です。

道路オーバーレイは追加せず、既存の地図／航空写真切替・災害取得方式を維持しています。
