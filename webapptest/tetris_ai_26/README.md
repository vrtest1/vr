# Neon Tetris

美しいネオンビジュアルと豊富な機能を備えたモダンなテトリスゲームです。

## 機能概要

### 🎮 基本機能
- **美しいネオンUI**: グラデーション背景とガラスモーフィズム効果
- **サウンドエフェクト**: Web Audio APIによる合成音（移動・回転・ドロップ・消去・ゲームオーバー）
- **ハイスコア保存**: localStorageに自動保存

### 🎯 特殊機能
- **Hold機能**: CキーまたはゲームパッドYボタンでミノを保留
- **ゴースト表示**: 着地位置を半透明で表示
- **Tスピン**: Tミノによる特殊消去（3角判定システム）
- **テトリス専用音**: 4段同時消し時に豪華なファンファーレ

## 操作方法

### キーボード
| キー | 動作 |
|------|------|
| ← → | 左右移動 |
| ↓ | ソフトドロップ |
| ↑ / X | 時計回り回転 |
| Z | 反時計回り回転 |
| C | Hold（保留） |
| SPACE | ハードドロップ |
| S | PLAY / RESTART |

### USBゲームパッド
| ボタン | 動作 |
|--------|------|
| 左スティック左右 | 左右移動 |
| 左スティック下 | ソフトドロップ |
| A (Button 0) | 反時計回り回転 |
| B (Button 1) | 時計回り回転 |
| X (Button 2) | ハードドロップ |
| Y (Button 3) | Hold（保留） |
| Start (Button 9) | PLAY / RESTART |

## 📱 スマホ版について

`mobile.html`をブラウザで開くとスマホ・タブレット向けの画面が表示されます。

### スマホ版の特徴
- **画面内ボタン**: タッチ操作専用のコントロールボタン
- **最適化されたUI**: 縦持ちに最適化されたレイアウト
- **同じ機能**: Hold、ゴースト表示、Tスピン、テトリス専用音など全機能搭載

### スマホ版の操作方法
| ボタン | 動作 |
|--------|------|
| ← → | 左右移動 |
| ↓ | ソフトドロップ |
| ↻ | 時計回り回転 |
| HOLD | ミノを保留 |
| DROP | ハードドロップ |

### デバイス切り替え
- PC版画面下部の「📱 スマホ版でプレイ」リンクからスマホ版へ
- スマホ版画面下部の「PC版でプレイ →」リンクからPC版へ

### index.html
ゲームのUI構造を定義
- ゲームキャンバス（300x600px）
- NEXT表示エリア（120x120px）
- HOLD表示エリア（120x120px）
- スコア・レベル・ハイスコア表示
- コントロール説明
- PLAYボタンとGAME OVERオーバーレイ

### style.css
美しいネオンビジュアルを実現
- グラデーション背景（紫系）
- ガラスモーフィズム効果（backdrop-filter）
- パルスアニメーション（タイトル）
- ホバーエフェクト（ボタン）
- レスポンシブレイアウト

### game.js
ゲームの全ロジックを実装（約860行）

#### 主要クラス・関数
- **SoundFX**: サウンドエフェクト管理
  - テトリス専用ファンファーレ（`playTetris`）
  - Tスピン検出
- **回転システム**: 壁蹴り機能付き
- **Holdシステム**: 1回/落下制限
- **Tスピン判定**: 中心周り4角の3角以上が埋まっているか

#### ゲーム定数
```javascript
COLS = 10        // 横10マス
ROWS = 20        // 縦20マス
BLOCK_SIZE = 30  // 1マス30px
```

#### 7種類のテトロミノ
1. **I** (シアン): 4マス直線
2. **O** (黄色): 2x2正方形
3. **S** (緑): S字
4. **Z** (赤): Z字
5. **J** (青): J字
6. **L** (オレンジ): L字
7. **T** (紫): T字

## スコアシステム

| 消去ライン | 基本点 |
|------------|--------|
| 1ライン | 40 × レベル |
| 2ライン | 100 × レベル |
| 3ライン | 300 × レベル |
| 4ライン（テトリス） | 1200 × レベル |

### Tスピン
| 消去ライン | 基本点 |
|------------|--------|
| 1ライン | 800 × レベル |
| 2ライン | 1200 × レベル |
| 3ライン | 1600 × レベル |

## 遊び方

1. `index.html`をブラウザで開く
2. 「PLAY」ボタンまたはSキー/ゲームパッドStartボタンで開始
3. ミノを操作して横一列を埋める
4. ラインを消してスコアを稼ぐ
5. ゲームオーバーになったら「RESTART」またはSキーで再開

## 技術仕様

- **対応ブラウザ**: Chrome, Firefox, Safari, Edge（Web Audio API対応）
- **入力デバイス**: キーボード、USBゲームパッド（Gamepad API）
- **保存機能**: localStorage（ハイスコアのみ）
- **オフライン対応**: インターネット接続不要
